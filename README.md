KeyPhantom 👻

KeyPhantom is an educational keylogger & clipboard logger written in Python for learning and lab testing only.
This repository includes a small HTTP server (server.py) and the main logger (KeyPhantom.py). The project automatically write logs to credentials.log 

⚠️ Warning: Do not run this on other people’s machines without explicit permission. Use only in a controlled lab environment.

Features 👻
Keystroke capture
Clipboard capture
Optionally sends data to local server.py (if implemented in project)
Local log storage 

Prerequisites:
Python 3.8+
(Optional) virtualenv for an isolated environment

Quick setup:
git clone https://github.com/Uhani007/KeyPhantom.git
cd KeyPhantom
